# ⚡ X$ Bot — Discord.js v14 + Express Panel

Bot de Discord completo con panel web desplegado en Railway.

## Variables de entorno requeridas en Railway

| Variable | Descripción |
|---|---|
| `DISCORD_TOKEN` | Token del bot |
| `GUILD_ID` | ID del servidor |
| `DISCORD_CLIENT_ID` | ID del bot |
| `PORT` | `8080` |
| `WEB_USER` | Usuario del panel web |
| `WEB_PASS` | Contraseña del panel web |
| `SESSION_SECRET` | Secreto de sesión (cualquier string) |
| `LOG_CHANNEL_ID` | (Opcional) Canal de logs |
